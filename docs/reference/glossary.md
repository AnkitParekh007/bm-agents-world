# Glossary

**Action** — A persisted request to execute one registered capability with a fixed context and payload.

**Adapter** — Trusted server implementation that talks to an external system or an explicit mock.

**Agent pack** — Declarative bundle of agents, skills, workflows, schemas, templates, policy, and guidance for an organization role.

**AG-UI** — Event protocol used by CopilotKit between the React experience and agent runtime.

**Approval contract** — Expiring human decision record bound to an action and payload hash.

**Artifact** — Run-owned evidence file plus metadata, served only after authorization.

**Capability** — Registered, risk-classified operation with explicit environment, approval, and adapter policy.

**Execution context** — Run, user, agent, pack, project, environment, tenant, and request timestamp.

**Pilot evaluation** — Human outcome/usefulness/reuse/false-positive/override feedback attached to a run.

**Standing policy** — Predefined permission for a bounded operation such as allowlisted non-production browser testing.

**Trusted gateway** — External authentication boundary allowed to inject identity headers over an isolated network path.
