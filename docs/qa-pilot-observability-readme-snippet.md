## QA pilot scorecard

When the QA pack is selected, BM Agents World now exposes a tenant/project-scoped pilot scorecard derived from durable run/action/approval state. Human reviewers can add per-run usefulness/outcome/manual-override feedback. Model token/cost telemetry is explicitly marked `not_instrumented` until provider usage is wired into the persistence contract.

See `docs/qa-pilot-observability.md`.
