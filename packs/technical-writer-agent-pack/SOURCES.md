## Application notes

- Project style and terminology override general style guides.
- Diátaxis is used as a content-type lens, not as a mandatory publishing platform.
- DITA support is optional and should only be enabled for projects that already use structured authoring.
- API documentation follows the approved repository contract version; the agent does not silently upgrade specifications.
- WCAG 2.2 is used as the accessibility baseline for rendered documentation and embedded media.
