# Implementation Roadmap

## Phase 1 — Internal documentation MVP

Onboard one project and one internal collection. Enable Jira, repository, workspace, Vale, link checking, build preview, artifact storage, policy, and human review. Keep all publication manual.

## Phase 2 — Developer and API documentation

Add source-code intelligence, OpenAPI/AsyncAPI validation, code-sample testing, diagrams, and documentation pull-request preparation.

## Phase 3 — Product and support documentation

Add approved Figma, Storybook, browser preview, support trends, knowledge-base workflows, screenshots, and release-documentation coordination.

## Phase 4 — Governed publication

Enable payload-bound CMS, Confluence, repository, Teams, and localization writes with separation of duties, immutable evidence, and rollback.

## Phase 5 — Content operations

Add inventories, freshness rules, ownership, analytics, zero-result analysis, localization readiness, quality dashboards, and recurring audits.

## Exit criteria

The pack is production-ready only after connector threat modeling, secret isolation, tenant isolation, policy tests, red-team evaluation, publication rollback, audit retention, owner training, and incident runbooks are validated.
