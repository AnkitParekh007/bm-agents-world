# Observability, Audit, and Evaluation

## Operational telemetry

Track workflow state, tool calls, validation outcomes, reviewer decisions, approval records, publication destinations, payload hashes, and failures. Do not log raw secrets or unrestricted source content.

## Content-quality evaluation

- Factual accuracy and source traceability.
- Task completion and verification.
- Audience fit and prerequisite clarity.
- Code-sample and command validity.
- Link and build health.
- Accessibility and localization readiness.
- Terminology and style consistency.
- Freshness, ownership, and version coverage.
- Search findability and feedback trends.

## AI-specific evaluation

Maintain test sets for unsupported claims, version confusion, unsafe commands, leaked secrets, fabricated citations, missing prerequisites, inaccurate UI labels, broken examples, inaccessible visuals, and cross-customer data mixing.

## Audit record

Each publication bundle records sources, source revisions, generated content, deterministic test results, reviewer identities, decisions, approvals, target, timestamp, and retention policy.
