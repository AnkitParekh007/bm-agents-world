# Project onboarding checklist

- [ ] Project, product, versions, branches, and documentation collections identified.
- [ ] Content owners, SMEs, reviewers, approvers, and escalation paths assigned.
- [ ] Repository, Jira, Confluence, API, design, support, analytics, and documentation connectors mapped.
- [ ] Style guide, terminology, content types, metadata, and accessibility baseline selected.
- [ ] Publication targets, preview environments, redirects, and rollback verified.
- [ ] Workload identities and vault references configured without raw secrets.
- [ ] Production and customer-data access restricted to bounded, redacted reads.
- [ ] Documentation build, lint, link, sample, contract, accessibility, and redaction checks pass.
- [ ] Approval policies and separation of duties tested.
- [ ] One internal content workflow completed before external publication is enabled.
