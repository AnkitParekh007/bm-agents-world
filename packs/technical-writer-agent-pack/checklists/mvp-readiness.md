# MVP readiness checklist

- [ ] Supervisor and required specialist agents enabled.
- [ ] At least one project and documentation collection onboarded.
- [ ] Isolated authoring workspace and artifact store operational.
- [ ] Repository read, documentation build, Vale, link checker, metadata validator, and preview operational.
- [ ] Source provenance and version binding required.
- [ ] Independent factual review required.
- [ ] Customer-facing publication remains manual or payload-bound approval-controlled.
- [ ] Secret and PII redaction tests pass.
- [ ] Unsupported-claim, stale-version, unsafe-command, broken-link, and inaccessible-content evaluations pass.
- [ ] Audit logs, retention, rollback, and incident procedures validated.
