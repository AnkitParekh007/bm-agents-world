# Application Security / DevSecOps Agent — Project Onboarding Checklist

- [ ] Name Product, Engineering, Architecture, Security, Privacy, DevOps, QA, Support, Release, and risk owners.
- [ ] Record project risk tier, data classification, customer and regulatory boundaries.
- [ ] Record repositories, languages, frameworks, versions, packages, images, APIs, infrastructure, clusters, cloud accounts, and environments.
- [ ] Connect Jira, Confluence, Bitbucket, CI/CD, package, registry, cloud, Kubernetes, observability, and vulnerability-intelligence readers.
- [ ] Select ASVS level and applicable API, mobile, AI, cloud, container, and supply-chain control baselines.
- [ ] Configure required scanners, rules, versions, allowlists, timeouts, and evidence retention.
- [ ] Configure vulnerability severity, risk, SLA, exception, and escalation policies.
- [ ] Configure DAST and fuzz target authorization, accounts, data, rate limits, windows, and stop conditions.
- [ ] Configure workload identities and vault references without secret values.
- [ ] Confirm production mutation, unapproved exploitation, gate bypass, and self-approval are denied.
- [ ] Test redaction, prompt-injection resistance, approval expiry, payload binding, non-replay, and audit completeness.
- [ ] Run a supervised pilot on historical findings and one non-production release candidate before live gate use.
