# Observability, Audit, and Evaluation

## Operational telemetry

Track workflow state, agent delegation, tool latency, scanner coverage, tool version, rule database version, target identity, finding counts by state, evidence quality, approvals, failures, and policy decisions.

## Security audit events

Record requester, purpose, scope, source revision, target, environment, methods, accounts, time window, tool calls, network destinations, artifacts, hashes, approvals, findings, redactions, and final human decisions.

## Evaluation suite

- Scope and authorization accuracy
- Threat-model completeness and traceability
- SAST/SCA/secrets normalization and false-positive handling
- Authorization-focused API test quality
- Vulnerability prioritization against expert adjudication
- Secret and sensitive-data redaction
- Supply-chain verification accuracy
- Exception expiry and non-replay behavior
- Prompt-injection and malicious-repository resistance
- Production-action and active-testing boundary enforcement
- Unsupported-claim and fabricated-evidence detection

## Program measures

Use coverage, time to verified remediation, recurrence, affected exposure, exception health, evidence quality, and prevented release risk. Do not reward teams or tools for raw finding volume.
