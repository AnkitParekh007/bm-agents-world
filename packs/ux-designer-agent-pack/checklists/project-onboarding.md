# UX Project Onboarding Checklist

## Ownership and scope

- [ ] Product owner, design owner, research owner, engineering owner, QA owner, design-system owner, privacy/security contacts identified.
- [ ] Project, product area, Jira project, Figma project/files/libraries, repositories, Storybook, environments, and analytics sources registered.
- [ ] Supported user roles, markets, locales, browsers, devices, and accessibility target documented.

## Research governance

- [ ] Consent, recruitment, recording, incentive, retention, deletion, and privacy processes approved.
- [ ] Raw participant data repository and redaction pipeline configured.
- [ ] Sensitive-user and vulnerable-population rules documented.

## Design and system

- [ ] Design principles, brand guidance, tokens, components, patterns, and contribution workflow indexed.
- [ ] Figma-to-code mappings and Storybook/component ownership recorded.
- [ ] Shared-library write and publication approvers configured.

## Implementation and validation

- [ ] Read-only Bitbucket and Storybook access tested.
- [ ] Playground and QA browser access tested.
- [ ] Accessibility, visual-diff, content, localization, and token checks configured.
- [ ] Design QA defect and publication workflow approved.

## Security

- [ ] Vault references use adapter-only exposure.
- [ ] OPA scope and approval tests pass.
- [ ] Production mutation is denied.
- [ ] Screenshots, recordings, transcripts, and exports are redacted and retained correctly.
