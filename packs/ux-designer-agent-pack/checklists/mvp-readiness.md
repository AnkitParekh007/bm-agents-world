# UX Agent MVP Readiness Checklist

- [ ] Jira/Confluence read works for one pilot project.
- [ ] Figma structured read works for one selected file and library.
- [ ] Bitbucket and Storybook read access works.
- [ ] Design repository and artifact store are available.
- [ ] Policy and capability broker deny raw secret access.
- [ ] Research data is redacted before model processing.
- [ ] Story-to-design-brief workflow completes with schema-valid output.
- [ ] Design/prototype workflow produces traceable artifacts in an isolated draft.
- [ ] WCAG/APG, contrast, target-size, token, and content checks run deterministically.
- [ ] Developer handoff contains flows, states, responsive, content, tokens, accessibility, and acceptance criteria.
- [ ] Design QA can inspect an approved playground or QA build without mutating it.
- [ ] Participant contact, recording, shared Figma writes, library publication, Jira/Teams publication, experiments, and production screenshots require approval.
- [ ] Audit records include source versions, tool calls, approvals, redaction, and artifact hashes.
- [ ] No participant identifiers, tokens, or credentials appear in model logs or artifacts.
