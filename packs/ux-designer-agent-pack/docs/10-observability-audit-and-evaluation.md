# Observability, Audit, and Evaluation

## Audit events

Record authentication, authorization, source reads, Figma versions, research evidence references, redaction, tool calls, generated artifacts, deterministic checks, approvals, publications, denials, and retention actions.

## Operational metrics

- Run success, failure, blocked, and approval-wait rates.
- Tool latency, error rate, and retry count.
- Figma/source-version drift detected before publication.
- Evidence completeness and artifact-schema validity.
- Redaction failures and prohibited-data detections.
- Approval consumption and expired approvals.

## UX quality metrics

- Research-to-decision traceability.
- Percentage of findings with evidence and confidence.
- Usability issue closure and retest rate.
- Accessibility coverage and unresolved severity.
- Design-system reuse versus duplicate components.
- Handoff clarification count and design QA defect rate.
- Post-release usability/support regressions.

## Agent evaluation

Use curated tasks and real historical artifacts with sensitive data removed. Score factual grounding, research rigor, bias awareness, accessibility, design completeness, system reuse, feasibility, privacy, handoff quality, uncertainty calibration, and policy compliance. Never score visual preference alone as objective quality.
