# MLOps / AI Platform Project Onboarding Checklist

- [ ] Project owner and support owner identified
- [ ] Environments and tenant/workspace boundaries registered
- [ ] Data classification and privacy requirements known
- [ ] Workload identity and secret references configured
- [ ] Experiment tracking workspace configured
- [ ] Model/prompt registry namespace configured
- [ ] Artifact/object-store prefixes configured
- [ ] Evaluation gates defined
- [ ] Serving pattern and SLOs defined
- [ ] GPU/quota requirements defined
- [ ] Model provider / egress policy approved
- [ ] Observability dashboards and alerts configured
- [ ] Cost allocation configured
- [ ] Production approval owner and rollback process defined
