# Product Owner Agent — Project Onboarding Checklist

## Accountability
- [ ] Named accountable Product Owner and delegate
- [ ] Product Manager, Business Owner, Scrum Master, Engineering Lead, Architect, UX, QA, DevOps, and release contacts
- [ ] Explicit decision-rights matrix

## Product and backlog
- [ ] Product strategy and Product Goal sources
- [ ] Jira project, boards, backlog, workflows, fields, taxonomy, and release model
- [ ] Definition of Ready and Definition of Done or equivalent policies
- [ ] Priority method and mandatory-work rules

## Evidence
- [ ] Research, feedback, support, analytics, design, architecture, API, database, quality, release, and incident sources
- [ ] Data classification, redaction, retention, and privacy thresholds
- [ ] Source-of-truth and conflict-resolution rules

## Access and security
- [ ] Project/environment-scoped workload identities
- [ ] Read and write identities separated
- [ ] Vault references verified
- [ ] OPA policy and approval routes tested
- [ ] Production mutation denied

## Validation
- [ ] Read-only context workflow tested
- [ ] Structured schemas validated
- [ ] Independent reviewer enabled
- [ ] Audit and evidence storage verified
- [ ] Payload-bound publication dry run completed
