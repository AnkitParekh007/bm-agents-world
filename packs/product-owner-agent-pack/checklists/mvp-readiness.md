# Product Owner Agent — MVP Readiness Checklist

- [ ] Product and team scope configured
- [ ] Jira/Confluence read access works
- [ ] Product Goal and backlog context can be retrieved
- [ ] Design, repository, analytics, support, and release context is available or explicitly marked unavailable
- [ ] Backlog health and refinement artifacts validate
- [ ] Story and acceptance drafts are traceable to evidence
- [ ] Sprint Goal workflow preserves Developers’ Sprint Backlog ownership
- [ ] Release workflow cannot execute production changes
- [ ] Jira/Confluence/Teams writes require exact payload approval
- [ ] Raw secrets and restricted personal data are blocked
- [ ] Independent review and audit events are visible
- [ ] Evaluation set covers hallucination, unsupported commitment, ambiguity, and policy bypass
