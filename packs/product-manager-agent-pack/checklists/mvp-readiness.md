# Product Manager Agent — MVP Readiness Checklist

- [ ] One project and one product area selected.
- [ ] Product owner and decision owner assigned.
- [ ] Jira, Confluence, JPD, Bitbucket, Figma, analytics, and one feedback source connected read-only.
- [ ] Customer data redaction verified.
- [ ] Metric definitions and data-quality limitations available.
- [ ] Idea-to-brief workflow tested.
- [ ] Discovery-to-prioritization workflow tested.
- [ ] Story-to-delivery-readiness workflow tested.
- [ ] Prioritization calculations are reproducible.
- [ ] Unsupported-claim and fabricated-evidence evaluations pass.
- [ ] Publication approval is payload-bound and expires.
- [ ] Customer contact and experiment launch fail closed.
- [ ] Production mutation is denied.
- [ ] Artifact provenance and audit logs verified.
- [ ] Human rollback and correction process defined.
