# Product Manager Agent — Project Onboarding Checklist

## Ownership and scope
- [ ] Product and product-area owners identified.
- [ ] Decision rights and escalation paths documented.
- [ ] Product lifecycle and strategic objectives documented.
- [ ] Supported users, roles, segments, and markets documented.

## Systems and evidence
- [ ] Jira/JPD projects and Confluence spaces mapped.
- [ ] Bitbucket repositories, design files, analytics projects, release systems, and feedback sources mapped.
- [ ] Metric dictionary and data-quality owners available.
- [ ] Customer, support, CRM, and research access minimized and redacted.
- [ ] Approved public-market research process defined.

## Governance
- [ ] Prioritization model and roadmap cadence documented.
- [ ] Customer-contact and research approval process documented.
- [ ] Experiment and feature-flag governance documented.
- [ ] Release and communication authority documented.
- [ ] Pricing, commercial, legal, security, privacy, and accessibility escalation paths documented.

## Runtime
- [ ] Read-only identities provisioned.
- [ ] Publication identities separated.
- [ ] Vault references configured.
- [ ] OPA policy tested.
- [ ] Audit and artifact retention configured.
- [ ] Synthetic test project available.
