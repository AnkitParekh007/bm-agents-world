# Business Analyst Agent — Project Onboarding Checklist

## Ownership and scope
- [ ] Project, product/process area, and business owner registered
- [ ] Product Owner and decision owners registered
- [ ] BA lead and artifact owners registered
- [ ] In-scope and prohibited use cases approved

## Evidence and systems
- [ ] Jira projects and issue types mapped
- [ ] Confluence/document spaces mapped
- [ ] Process, policy, glossary, contract, and data-catalog sources registered
- [ ] Bitbucket, Figma, analytics, and database access decisions recorded
- [ ] Evidence classification and retention approved

## Requirements lifecycle
- [ ] Requirement identifier and status conventions defined
- [ ] Baseline and change-control process defined
- [ ] Traceability relationships defined
- [ ] Definition of ready and acceptance conventions defined
- [ ] UAT ownership and sign-off authority defined

## Security and approvals
- [ ] Workload identities created
- [ ] Vault references configured
- [ ] OPA policy tested
- [ ] Publication and restricted-data approvers configured
- [ ] Production access confirmed read-only

## Validation
- [ ] Benchmark request completed
- [ ] Ambiguity, traceability, process, and UAT evaluations passed
- [ ] Audit record and artifact retention verified
- [ ] Owners approve activation
