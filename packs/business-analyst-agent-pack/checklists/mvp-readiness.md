# Business Analyst Agent — MVP Readiness Checklist

- [ ] Supervisor, work-context, elicitation, requirements, traceability, independent-review, evidence, and policy agents enabled
- [ ] Jira and Confluence read access works with project filters
- [ ] Requirements linter and ambiguity detector pass benchmark cases
- [ ] Diagram rendering and artifact versioning work
- [ ] Payload-bound approval cannot be replayed or reused after payload change
- [ ] Official Jira/Confluence writes are disabled or approval-gated
- [ ] Database access is metadata-first, parameterized, bounded, and read-only
- [ ] Production mutation attempts are denied and audited
- [ ] Secret values never appear in model context, artifacts, or logs
- [ ] Traceability links can be created, queried, diffed, and exported
- [ ] Human-only decisions are blocked
- [ ] Evidence lineage and retention are verified
- [ ] Pilot project owner accepts the operating model
