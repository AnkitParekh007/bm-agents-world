# Implementation Roadmap

## Phase 0 — Governance
Confirm decision forums, approvers, data classification, exceptions, identity, audit, retention, and model-data policies.

## Phase 1 — Read-only assistant
Connect Jira, Confluence, Bitbucket, architecture knowledge, artifacts, and policy. Produce current-state models, quality scenarios, diagrams, ADR drafts, and review drafts.

## Phase 2 — Governed publication
Add payload-bound publication, immutable decision records, review workflow, cross-pack handoffs, and OpenAPI/AsyncAPI checks.

## Phase 3 — Runtime evidence
Add read-only database, cloud, Kubernetes, observability, identity, security, cost, and vendor metadata; capacity, cost, migration, and threat analysis.

## Phase 4 — Cross-agent orchestration
Invoke Product, UX, Angular, Java, Python, Database, QA, and DevOps packs and aggregate conformance evidence.

## Phase 5 — Controlled POCs
Allow human-approved bounded non-production experiments with synthetic/masked data, cost ceilings, egress controls, cleanup, and stop conditions.

## Phase 6 — Architecture operations
Add capability/application portfolio views, reference architectures, technology radar, standards, exceptions, metrics, and periodic revalidation.
