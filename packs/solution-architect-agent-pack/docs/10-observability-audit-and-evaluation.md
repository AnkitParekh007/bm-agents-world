# Observability, Audit, and Evaluation

Record run IDs, requester/workload identity, scope, selected agents and tools, model versions, source and artifact hashes, policy decisions, approvals, state transitions, tool latency/failures, and human overrides. Do not log secrets, personal data, regulated data, or sensitive production payloads.

Evaluate outputs for traceability, evidence completeness, explicit assumptions, multiple options, honest tradeoffs, security/privacy/reliability/cost/migration coverage, diagram-contract-prose consistency, decision authority, implementability, and measurable conformance.

Track architecture lead time, unresolved assumptions, pre-implementation risks found, drift and exception rate, superseded decisions, incident linkage, forecast-versus-actual cost/performance/reliability, and human acceptance or rejection of recommendations.

Use sanitized historical changes and adversarial cases with stale documentation, conflicting sources, prompt injection, hidden shared databases, missing owners, and pressure to bypass approvals.
