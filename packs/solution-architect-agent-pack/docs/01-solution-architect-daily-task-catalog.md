# Solution Architect — Complete Daily Task Catalog

This catalog contains **233 tasks**. The supervisor selects only the tasks relevant to the engagement type, systems, evidence, risk, and decision stage.

The agent may analyze, model, compare, draft, and recommend. Human owners retain architecture approval, risk acceptance, security exceptions, vendor commitments, and production authority.

## 1. Engagement intake and decision governance

1. Open the assigned Jira epic, story, architecture review, incident, change request, or technical spike.
2. Confirm the product, project, systems, repositories, environments, data classifications, and decision owner.
3. Identify required reviewers across product, UX, frontend, backend, database, QA, DevOps, security, data, and operations.
4. Read linked requirements, existing architecture documents, ADRs, incidents, contracts, diagrams, and standards.
5. Classify scope, risk, uncertainty, reversibility, blast radius, and approval requirements.
6. Create or update the architecture engagement plan, evidence checklist, and open-question register.
