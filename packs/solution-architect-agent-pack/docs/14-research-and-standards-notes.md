# Research and Standards Notes

- TOGAF can inform governance, capability, repository, and architecture-development practices; this pack uses a lightweight delivery-oriented subset and does not reproduce licensed text.
- ArchiMate can provide interoperable enterprise, application, data, and technology views; licensing and tool choice remain organizational decisions.
- C4 supports context, container, component, and deployment communication.
- ATAM informs quality-attribute tradeoff, sensitivity, risk, and non-risk analysis.
- ADRs preserve individual decision context and consequences.
- AWS, Azure, and Google Cloud well-architected guidance are used as multi-quality lenses, not vendor mandates.
- NIST CSF 2.0, NIST SP 800-207, and OWASP threat-modeling guidance inform security and risk.
- OpenAPI 3.2 and AsyncAPI support machine-readable HTTP and event contracts when repository tooling permits.
- MCP resources, prompts, and tools are separately governed; an MCP connection does not make a server trustworthy.

External guidance is advisory. Actual repositories, runtime topology, contracts, incidents, classification, vendor agreements, ownership, and human authority control the final design.
