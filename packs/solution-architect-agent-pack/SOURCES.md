# Sources and Standards Baseline

This pack uses the following references as guidance. It does not reproduce licensed standards text; organization-specific licensed content must be supplied through approved knowledge sources.

## Enterprise and solution architecture

- TOGAF Standard, 10th Edition: https://www.opengroup.org/togaf-standard-10th-edition-downloads
- ArchiMate 3.2 information: https://www.opengroup.org/archimate-licensed-downloads
- C4 model: https://c4model.com/
- CMU SEI Architecture Tradeoff Analysis Method: https://www.sei.cmu.edu/library/architecture-tradeoff-analysis-method-atam/
- Architecture Decision Record overview: https://martinfowler.com/bliki/ArchitectureDecisionRecord.html

## Cloud architecture

- AWS Well-Architected Framework: https://docs.aws.amazon.com/wellarchitected/latest/framework/welcome.html
- Azure Well-Architected Framework: https://learn.microsoft.com/azure/well-architected/
- Azure Architecture Center: https://learn.microsoft.com/azure/architecture/
- Google Cloud Architecture Center: https://docs.cloud.google.com/architecture

## Contracts and agent integration

- OpenAPI Specification 3.2.0: https://spec.openapis.org/oas/v3.2.0.html
- AsyncAPI Specification: https://www.asyncapi.com/docs/reference/specification/latest
- Model Context Protocol: https://modelcontextprotocol.io/ and https://github.com/modelcontextprotocol

## Usage notes

Cloud frameworks are quality lenses, not mandates to select a specific vendor. TOGAF and ArchiMate licensing must be checked before embedding licensed content. Final architecture must be reconciled with repository evidence, runtime evidence, organizational standards, vendor agreements, team ownership, and human decision authority.
