# Observability, Audit, and Evaluation

Every architecture run records source references, contract digests, tool versions, lint/test outputs, dependency graphs, consumer-impact evidence, approvals, publication hashes, and final decisions.

Operational specifications cover HTTP, RPC/gRPC, and messaging traces/metrics/logs using project-approved OpenTelemetry semantic conventions. High-cardinality and sensitive payload fields are opt-in and redacted.

Agent quality is evaluated on factual grounding, contract validity, compatibility precision/recall, security finding quality, consumer-impact completeness, test reproducibility, and absence of unauthorized changes—not on document volume.
