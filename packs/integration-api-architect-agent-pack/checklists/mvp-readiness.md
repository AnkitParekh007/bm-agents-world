# MVP Readiness Checklist

- [ ] Supervisor can read one Jira story and discover provider/consumer repos
- [ ] Existing OpenAPI/AsyncAPI/proto/GraphQL contracts can be indexed
- [ ] OpenAPI/AsyncAPI/schema/proto/GraphQL validation works
- [ ] Breaking-change detection works
- [ ] Consumer impact can be linked to known owners
- [ ] API security review produces evidence-backed findings
- [ ] Contract tests can run in playground/QA
- [ ] Gateway/broker/IdP production access is read-only
- [ ] Publication requires payload-bound approval
- [ ] Evidence bundle is immutable and auditable
- [ ] No raw secrets reach model context
- [ ] Production change request can be handed to DevOps/SRE deterministically
