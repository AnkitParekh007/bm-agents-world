# Sources and Standards

Research baseline checked for this pack on 2026-08-08.

1. OpenAPI Initiative — OpenAPI Specification 3.2.0: https://spec.openapis.org/oas/v3.2.0.html
2. AsyncAPI Initiative — Specification 3.1.0 release/reference: https://www.asyncapi.com/docs/reference
3. JSON Schema — Draft 2020-12: https://json-schema.org/draft/2020-12
4. CloudEvents Specification repository/releases: https://github.com/cloudevents/spec
5. RFC 9457 — Problem Details for HTTP APIs: https://www.rfc-editor.org/rfc/rfc9457
6. RFC 9700 — Best Current Practice for OAuth 2.0 Security: https://www.rfc-editor.org/info/rfc9700/
7. RFC 9449 — OAuth 2.0 Demonstrating Proof of Possession (DPoP): https://www.rfc-editor.org/info/rfc9449/
8. OWASP API Security Project: https://owasp.org/API-Security/
9. OpenTelemetry HTTP semantic conventions: https://opentelemetry.io/docs/specs/semconv/http/
10. OpenTelemetry RPC/gRPC semantic conventions: https://opentelemetry.io/docs/specs/semconv/rpc/
11. OpenTelemetry messaging semantic conventions: https://opentelemetry.io/docs/specs/semconv/messaging/
12. gRPC health checking guidance: https://grpc.io/docs/guides/health-checking/

Project-approved versions, vendor capabilities, and compatibility requirements always override a generic latest-version assumption.
