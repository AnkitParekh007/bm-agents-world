# Customer Success Agent — Project Onboarding Checklist

- [ ] Project/product scope registered.
- [ ] CRM account scope and ownership model registered.
- [ ] Customer Success platform scope registered, if used.
- [ ] Jira/Confluence and product documentation access configured.
- [ ] Support system and SLA read access configured.
- [ ] Approved product-usage/analytics views configured.
- [ ] Contract/entitlement metadata fields approved for read access.
- [ ] Customer lifecycle stages and service models documented.
- [ ] Health-score dimensions, weights, owners, and override rules documented.
- [ ] Success-plan template and value measures approved.
- [ ] Customer-contact approval and sender identities configured.
- [ ] Renewal/expansion commercial boundaries documented.
- [ ] Tenant isolation and data-classification controls tested.
- [ ] Retention and deletion policy configured for CS artifacts.
- [ ] Cross-pack handoffs to Support, Product, Engineering, Release, SRE, Security, and Compliance tested.
- [ ] Customer-facing claim and commitment review process approved.
- [ ] Production connectors verified read-only and bounded.
