# Customer Success Agent — MVP Readiness

## Required
- [ ] Account/customer scope is enforced end to end.
- [ ] CRM/CS reads are minimum-necessary and read-only.
- [ ] Product-usage reads use approved metrics and tenant isolation.
- [ ] Support and incident status comes from authoritative systems.
- [ ] Health scores are deterministic, explainable, and driver-based.
- [ ] Customer-facing drafts identify evidence and prohibited commitment types.
- [ ] No raw secrets reach model context.
- [ ] No production mutation tool is available to free-form agents.
- [ ] Customer contact and official writes require payload-bound approval.
- [ ] Commercial commitments are denied.
- [ ] Cross-customer data leakage tests pass.
- [ ] Reviewer agent is enabled for material customer-facing and risk artifacts.
- [ ] Audit records contain run, customer, purpose, tools, approvals, and payload hashes.

## Recommended MVP demonstration
1. Select a test customer.
2. Build Customer 360.
3. Draft success plan.
4. Calculate health and explain drivers.
5. Detect one simulated adoption/support risk.
6. Prepare a QBR/EBR draft.
7. Prepare renewal-readiness evidence without pricing/contract language.
8. Request approval for a customer email and prove that changed payloads require reapproval.
