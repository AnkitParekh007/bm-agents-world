# Scrum Master Agent — Project Onboarding Checklist

- [ ] Name the product, project, Scrum Team, Product Owner, Developers, and human Scrum Master owner.
- [ ] Record Sprint cadence, time zone, event schedules, and approved stakeholder groups.
- [ ] Connect Jira and Confluence read access.
- [ ] Connect Bitbucket, CI/CD, QA, release, and observability read-only context.
- [ ] Configure aggregated delivery metrics and minimum group size.
- [ ] Record Product Goal, Definition of Done, working agreements, and escalation paths.
- [ ] Configure project-, team-, action-, and expiry-bound capability leases.
- [ ] Configure calendar, Jira, Confluence, and Teams write approvals.
- [ ] Confirm production mutation is denied.
- [ ] Confirm employment decisions and individual productivity scoring are denied.
- [ ] Agree retrospective privacy, retention, and publication rules with the team.
- [ ] Test audit, redaction, approval expiry, and replay protection.
- [ ] Run one read-only Sprint-cycle pilot.
- [ ] Obtain Scrum Team feedback before enabling publication.
