# Data Engineering Project Onboarding Checklist

## Ownership and purpose
- [ ] Product, data, technical, support, security, and privacy owners identified
- [ ] Data product purpose, users, outcomes, and criticality approved
- [ ] Sources, consumers, contracts, service levels, and business terms inventoried

## Repository and runtime
- [ ] Repository, branches, code owners, build, tests, packaging, and release documented
- [ ] Python, Spark, JVM, connector, orchestrator, table-format, and catalog versions recorded
- [ ] Local, playground, QA, and production topology recorded

## Data and governance
- [ ] Dataset and field classification approved
- [ ] Access, masking, retention, residency, deletion, and audit rules approved
- [ ] Bounded source queries and evidence redaction configured

## Operations
- [ ] Schedules, dependencies, quality, freshness, lineage, monitoring, and alerts documented
- [ ] Backfill, replay, checkpoint, snapshot, rollback, and recovery procedures documented
- [ ] Incident, release, and support handoffs approved

## Agent controls
- [ ] MCP and plugin allowlists approved
- [ ] Workload identities and vault references configured
- [ ] Approval groups and payload requirements configured
- [ ] Production free-form mutations denied and tested
