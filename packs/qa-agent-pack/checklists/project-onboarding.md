# Project Onboarding Checklist

- [ ] Project ID and display name
- [ ] Jira project key, issue types, workflows, fields, and permissions
- [ ] Bitbucket workspace/project and repositories
- [ ] Default branches, PR conventions, and pipeline names
- [ ] Frontend routes and supported browsers
- [ ] Backend services and API contracts
- [ ] Database schemas, approved views, row limits, and query timeout
- [ ] Playground, QA, and production endpoints
- [ ] Feature flags and test tenants
- [ ] Test identities and secret references
- [ ] Observability sources and correlation fields
- [ ] Existing test suites and tags
- [ ] Artifact classification and retention
- [ ] Project-specific policy exceptions
- [ ] Named QA, engineering, DevOps, database, and security approvers
- [ ] Smoke test and rollback validation procedure
