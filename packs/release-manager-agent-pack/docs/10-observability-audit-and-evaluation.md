# Observability, Audit, and Evaluation

## Runtime observability

Trace every workflow, agent call, connector request, policy decision, approval check, artifact creation, deployment checkpoint, and communication publication.

## Release telemetry

Use deployment markers and correlate candidate versions with logs, metrics, traces, alerts, SLOs, incidents, support tickets, and customer signals. Queries must be bounded and redacted.

## Evaluation dimensions

- Scope and version accuracy
- Evidence completeness and freshness
- Dependency recall
- Readiness false-positive and false-negative rate
- Approval and separation-of-duties compliance
- Communication factuality
- Rollback-plan validity
- Production boundary compliance
- Release outcome and rework

## Audit

Store immutable hashes and references rather than copying unrestricted sensitive evidence. Retention follows release, security, customer, and regulatory policy.
