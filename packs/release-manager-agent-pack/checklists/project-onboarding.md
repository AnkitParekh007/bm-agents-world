# Release Manager Agent — Project Onboarding Checklist

- [ ] Project, service, repository, component, and owner inventory confirmed
- [ ] Release types and risk model defined
- [ ] Environments, regions, clusters, databases, and deployment targets mapped
- [ ] Release calendar, blackout periods, maintenance windows, and timezones configured
- [ ] Jira versions, change records, and service catalog mappings configured
- [ ] CI/CD pipelines and artifact registries mapped
- [ ] Versioning and artifact identity conventions documented
- [ ] Quality, security, database, platform, business, and support readiness criteria defined
- [ ] Deployment and rollback ownership defined
- [ ] Production operator or deterministic pipeline identified
- [ ] Observability dashboards, SLOs, alerts, and deployment markers configured
- [ ] Approval authorities and separation of duties configured
- [ ] Vault references and workload identities created
- [ ] Data classification, redaction, retention, and audit rules approved
- [ ] Standard and emergency release workflows rehearsed in non-production
- [ ] Production free-form mutation technically blocked
