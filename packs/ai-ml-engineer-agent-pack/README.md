# AI/ML Engineer Agent Pack

A governed operating pack for an enterprise AI/ML Engineer Agent covering classical machine learning, deep learning, NLP/vision/audio/multimodal systems, LLM and RAG engineering, fine-tuning, experimentation, evaluation, responsible AI, AI security, model registries, serving, MLOps, monitoring, and model lifecycle management.

## Design goals
- Project- and environment-scoped access.
- Reproducible data, experiments, evaluations, and model artifacts.
- Clear separation of skills, MCP servers, deterministic plugins, specialist agents, and artifacts.
- Human-owned risk acceptance and high-impact AI decisions.
- No raw secrets in model context.
- No direct free-form production mutation.
- Independent review for high-risk candidates.
