# AI/ML Project Onboarding Checklist

- [ ] Project/work-item owners identified.
- [ ] AI/ML suitability and baseline documented.
- [ ] Risk tier assigned.
- [ ] Repositories and branches mapped.
- [ ] Dataset/catalog sources and owners registered.
- [ ] Purpose, privacy, retention, residency, and license checks completed.
- [ ] Experiment tracker and artifact storage configured.
- [ ] Model registry configured.
- [ ] Approved model providers and budgets configured if needed.
- [ ] Evaluation datasets and success metrics defined.
- [ ] Security and responsible-AI review path assigned.
- [ ] Non-production compute limits configured.
- [ ] Production access limited to bounded read-only telemetry.
- [ ] Approval policies and human owners configured.
- [ ] Rollback and incident ownership defined before production release.
