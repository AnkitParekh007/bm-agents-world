
# SRE Project Onboarding Checklist

- [ ] Project, service, owners, and service tier recorded
- [ ] Critical user journeys and business impact documented
- [ ] Environments, regions, tenants, and topology recorded
- [ ] Dependencies and third-party providers mapped
- [ ] Data classification and redaction rules approved
- [ ] SLI and SLO ownership identified
- [ ] Metrics, logs, traces, alerts, and dashboards inventoried
- [ ] On-call schedules and escalation paths confirmed
- [ ] Runbooks, rollback, degraded modes, RTO, and RPO documented
- [ ] Release, feature, configuration, and database context connected
- [ ] Read-only identities and query limits tested
- [ ] Production mutations denied to free-form agents
- [ ] Communication approval path configured
- [ ] Historical incident evaluation dataset prepared
- [ ] Retention, audit, and evidence policies approved
