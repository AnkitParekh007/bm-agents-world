# MVP Readiness Checklist

- [ ] Supervisor and specialist agents are registered.
- [ ] Skill, MCP, plugin and artifact registries validate.
- [ ] OPA policy is deployed and tested.
- [ ] Production connectors are read-only.
- [ ] Vault uses references and workload identity.
- [ ] At least one framework mapping is approved.
- [ ] Evidence manifest and freshness checks work.
- [ ] Audit and finding schemas validate.
- [ ] Independent review is enforced for material closure.
- [ ] Risk acceptance cannot be performed by the agent.
- [ ] Official publication requires payload-bound approval.
- [ ] Cross-pack remediation path is tested.
- [ ] Audit logs capture tool calls, decisions and approvals.
