# Project Onboarding Checklist

- [ ] Identify accountable business/product/engineering owners.
- [ ] Register project, environments and data classifications.
- [ ] Identify applicable frameworks, laws and contractual commitments.
- [ ] Record organization-approved legal interpretations where needed.
- [ ] Map architecture, data flows, identities, vendors and AI components.
- [ ] Map normalized controls and control owners.
- [ ] Configure read-only evidence connectors and purpose-bound identities.
- [ ] Define evidence frequency and retention.
- [ ] Configure approval policies and exception workflow.
- [ ] Validate no raw secrets enter model context.
- [ ] Run initial gap assessment and independent review.
- [ ] Obtain human approval of baseline scope and mappings.
