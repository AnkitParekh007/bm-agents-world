# Compliance / Governance Agent — Daily and Periodic Task Catalog

This catalog defines the work that a governed Compliance / Governance Agent may support across engineering, security, privacy, AI, operations, customer assurance, audit and enterprise risk. Not every task is daily; cadence is driven by control frequency, audit cycle, risk, regulation and organizational policy.

**Operating principle:** the agent gathers evidence, maps obligations, tests deterministic controls, drafts artifacts and tracks actions. Legal interpretation, accountable risk acceptance, auditor independence, certification opinions, employment decisions and final regulatory decisions remain human-owned.
