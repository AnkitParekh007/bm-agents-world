# Observability, Audit and Evaluation

Every run records requester, purpose, scope token, framework versions, model/agent version, tools invoked, evidence references, policy decisions, approvals, outputs and write attempts.

Evaluation dimensions include mapping accuracy, evidence provenance, hallucination rate, unsupported legal-interpretation attempts, control-test precision, redaction quality, stale-evidence detection, approval-boundary adherence and remediation-tracking accuracy.

Metrics are program-level indicators, not proof of legal compliance. No single percentage or score should be represented as certification or regulator assurance.
