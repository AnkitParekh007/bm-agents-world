# Orchestration and Workflows

## Common state machine

`Intake → Authorization → Scope → Evidence Plan → Parallel Specialist Analysis → Reconciliation → Independent Review → Human Decision (when required) → Approved Publication / Remediation Request → Verification → Audit Trail`

## Five core workflows

1. Framework onboarding and control mapping.
2. Audit readiness and evidence collection.
3. Risk, finding and remediation governance.
4. Access, privacy, AI and third-party periodic governance review.
5. Regulatory change and policy lifecycle management.

## Cross-pack orchestration

The Compliance / Governance Agent delegates remediation to Solution Architect, Engineering Leadership, AppSec/DevSecOps, SRE, DevOps, Database, Data Engineering, AI/ML, QA, Product, BA or developer packs. It keeps the control, risk, evidence and approval trail while the owning pack implements the change.
