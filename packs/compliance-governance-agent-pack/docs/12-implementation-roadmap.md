# Implementation Roadmap

## Phase 1 — Read-only governance MVP
Framework registry, policy/control catalog, project scope, evidence inventory, Jira/Confluence read, artifact store and OPA policy.

## Phase 2 — Evidence automation
SIEM, cloud, IAM, vulnerability, repository and database metadata collectors; evidence freshness and hashing.

## Phase 3 — Audit and risk workflows
Audit readiness, findings, remediation, exceptions and management review packs.

## Phase 4 — Privacy, vendor and AI governance
Processing inventory, vendor evidence, AI system inventory and dedicated approval workflows.

## Phase 5 — Controlled publication
Payload-bound Jira/Confluence/GRC writes, customer assurance drafts and approved report publication.

## Phase 6 — Continuous controls monitoring
Scheduled deterministic checks, drift detection, expiring exceptions, control-owner notifications and cross-pack remediation orchestration.
