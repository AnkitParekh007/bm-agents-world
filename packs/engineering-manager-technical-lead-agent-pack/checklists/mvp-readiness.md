# MVP Readiness Checklist

## Required MVP capabilities
- [ ] Select Engineering Manager, Technical Lead, or hybrid profile
- [ ] Read scoped Jira, Bitbucket, CI/CD, architecture, and aggregate metrics
- [ ] Generate daily summary, delivery plan, dependency map, risk register, and technical review
- [ ] Delegate to existing specialist packs and retain evidence references
- [ ] Enforce payload-bound approvals for all external writes
- [ ] Deny production mutation and raw-secret access

## People-safety requirements
- [ ] No employee-record connector in the default MVP
- [ ] No individual productivity scores or automated performance judgments
- [ ] No hiring, promotion, compensation, discipline, termination, or wellbeing decisions
- [ ] Restricted workflows have separate storage, retention, audit, and human initiation

## Quality requirements
- [ ] Forecasts include ranges, assumptions, and confidence
- [ ] Metrics include definitions, context, and anti-gaming notes
- [ ] High-risk recommendations receive independent review
- [ ] Conflicting evidence is surfaced
- [ ] Agent output is evaluated for accuracy, fairness, privacy, and usefulness
