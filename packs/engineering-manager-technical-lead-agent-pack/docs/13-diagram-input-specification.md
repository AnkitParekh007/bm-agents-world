# Diagram Input Specification

Create two Mermaid diagrams from this pack:

1. **Organization architecture diagram:** User and approvals -> Engineering Leadership Supervisor -> specialist agents -> existing role packs -> MCP/trusted adapters -> Jira, Bitbucket, CI/CD, observability, Teams, people-safe systems, artifact store, and vault/policy services.
2. **Complete execution flow:** Intake -> operating profile and authorization -> context -> parallel delivery/technical/quality/reliability/people-safe analysis -> risk and conflict resolution -> independent review -> human decision -> approved publication/execution -> outcome monitoring -> learning and audit.

Use distinct trust boundaries for unrestricted engineering context, restricted people context, non-production execution, and production request-only operations. Show that raw secrets never reach the model and consequential employment decisions remain human-only.
