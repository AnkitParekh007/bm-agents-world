# Permissions, Approvals, and Guardrails

## Safe autonomous actions

Scoped reading, repository analysis, metric calculation, draft artifacts, planning scenarios, evidence aggregation, and isolated workspace analysis.

## Approval-controlled actions

Jira/Confluence/Teams publication, Bitbucket writes and pull requests, CI retries, incident updates, non-production execution, release recommendations, technical-decision publication, and people-sensitive artifact publication.

## Human-only decisions

Performance ratings, promotion, compensation, hiring/rejection, discipline, termination, medical or wellbeing assessment, staffing or budget commitment, vendor or contractual commitment, residual-risk acceptance, final release approval, and production mutation.

## Metric guardrail

Never use commits, pull requests, lines of code, ticket counts, messages, hours online, or similar activity as an individual performance score. Engineering metrics must be contextual, balanced, team/service-level where possible, and used to improve systems rather than punish people.
