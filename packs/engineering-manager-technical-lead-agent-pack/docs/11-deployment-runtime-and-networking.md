# Deployment, Runtime, and Networking

Run the supervisor in a control plane and specialists in isolated, short-lived workers. Separate general engineering context from restricted people and recruiting contexts. Route all external access through allow-listed MCP adapters and an egress proxy. Use workspace, project, repository, environment, and purpose claims in every capability lease.

Production systems expose read-only redacted evidence to the agent. Approved production actions are executed by deterministic CI/CD, incident, or operations systems—not by free-form model shell access.
