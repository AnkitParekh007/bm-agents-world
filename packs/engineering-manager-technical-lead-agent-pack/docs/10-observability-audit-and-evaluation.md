# Observability, Audit, and Evaluation

Every run records authorization, operating profile, project/team scope, tools, evidence references, assumptions, confidence, decisions requested, approvals, outputs, and external execution references.

Evaluation dimensions include factual accuracy, forecast calibration, evidence completeness, decision usefulness, policy compliance, data minimization, fairness, delivery outcomes, quality, reliability, developer experience, and false-positive escalation rate. Agent success is not measured by the number of tickets, messages, or people actions generated.
