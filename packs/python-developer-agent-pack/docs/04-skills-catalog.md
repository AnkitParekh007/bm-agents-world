## Skill contract

Each skill definition must declare: semantic version; supported Python/framework profiles; required inputs; output schema; allowed tools; read/write classification; required approvals; command/network/resource budget; deterministic validators; redaction rules; and golden evaluation cases.

## Promotion lifecycle

`draft -> sandbox-tested -> security-reviewed -> pilot -> approved -> deprecated -> retired`. A skill cannot be enabled organization-wide solely because it produced one successful patch.
