# Python Project Onboarding Checklist

- [ ] Record project, repository, owners, code owners, and Jira mapping
- [ ] Record Python versions, operating systems, framework, and application profile
- [ ] Record dependency manager, lockfiles, package indexes, and proxy
- [ ] Record setup, lint, format, type, test, coverage, build, package, and container commands
- [ ] Identify protected paths, generated code, migrations, and release files
- [ ] Inventory databases, schemas, read replicas, migration tools, and data classification
- [ ] Inventory queues, caches, schedulers, storage, and external services
- [ ] Inventory environments, endpoints, feature flags, and deployment model
- [ ] Configure workload identities, secret references, and capability leases
- [ ] Configure network and command allowlists
- [ ] Configure branch protections, approvals, and publication policy
- [ ] Configure observability and artifact retention
- [ ] Run golden tasks and adversarial security evaluations
- [ ] Obtain repository owner, security, data, and DevOps sign-off
