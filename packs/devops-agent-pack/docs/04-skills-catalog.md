## Skill contract

Every implemented skill should declare:

- input and output schema
- supported tools and versions
- required project and environment scope
- read, sandbox-write, shared-write, or production-executor classification
- deterministic validations
- failure and timeout behavior
- evidence and redaction requirements
- approval and payload-binding requirements
